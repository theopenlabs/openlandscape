# Security

## Reporting a problem

Please email **hello@openlandscape.app**. Do not open a public issue or pull request for a security problem.

Please include:

- What the problem is, and what someone could do with it.
- How to reproduce it: the steps, the address or file, and what you saw.
- Whether it affects the live site (openlandscape.app), this code, or both.
- How we can reach you, and whether you would like to be thanked by name once it is fixed.

Please do not access other people's accounts or data, and do not run tests that slow the site down.

## What to expect

- We reply within 3 working days to say we have it.
- We tell you what we plan to do, and roughly when.
- We tell you when it is fixed, and agree with you when to talk about it in public.
